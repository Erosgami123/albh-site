# Site ALBH

Site vitrine statique en français pour ALBH (Le Chemin des Arômes), avec informations commerciales et pages de conformité utiles pour Stripe.

## Aperçu local

Servir le dossier `dist/` avec un serveur HTTP statique.

## Publication

Le site est configuré pour OpenAI Sites dans `.openai/hosting.json`. Le domaine prévu est `albh.online`.

## Avant mise en service commerciale

- Activer et tester la boîte `contact@albh.online`.
- Remplacer ou compléter les descriptions, tarifs et délais par les offres réellement vendues.
- Faire valider les textes juridiques par un professionnel selon la clientèle et les contrats utilisés.
- Ajouter les liens de paiement Stripe seulement après création des produits et prix réels dans le compte marchand.
